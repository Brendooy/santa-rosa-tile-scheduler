SANTA ROSA TILE SCHEDULER  -  START HERE
=========================================

1. EXTRACT
   Right-click the ZIP file > "Extract All...". Put the folder anywhere you like
   (Desktop, Documents, a USB stick). Do NOT run it from inside the ZIP.

2. LAUNCH
   Open the extracted folder and double-click:
       Santa Rosa Tile Scheduler.exe

   The first time, Windows may show a blue box "Windows protected your PC"
   because this app is not code-signed. Click "More info", then "Run anyway".
   (This only happens once per computer.)

   Nothing to install. No Python, no administrator rights, no internet needed.

3. USE IT
   The app opens on the weekly schedule. Your changes save automatically; the
   top-right corner says "All changes saved" (or shows a red warning if they
   could not be saved). Close the window whenever you are done.

   Your data is kept in:  %APPDATA%\Santa Rosa Tile Scheduler
   (Data & backups tab > "Open folder" takes you there.)

MOVING TO ANOTHER COMPUTER
   Data & backups tab > "Export All Data"  ->  copy the file  ->  on the other
   computer open the app > "Import Data". Google sign-in is never exported;
   reconnect Google Calendar on the new computer.
